# Brand Icons

Brand logos used by the reusable BrandIcon component live in this directory.

## Sources

The icons are local SVG assets sourced from Simple Icons:

GitHub, LinkedIn, Facebook, and WhatsApp.

Source:
https://github.com/simple-icons/simple-icons

Simple Icons is distributed under CC0-1.0, while individual icons can have their own source or licensing requirements. Check the icon metadata before reusing or replacing an asset.

## Adding a brand

1. Add the SVG file to public/icons/brands/.
2. Register it in config/brand-icons.ts.
3. Use it anywhere with BrandIcon:

```tsx
<BrandIcon icon="facebook" />
```

Brand names and trademarks remain the property of their respective owners.
