# Project Technology Icons

The Projects section reuses the local technology SVGs from the Skills section where possible and keeps additional project-specific brand icons local as well.

## Simple Icons

Additional technology icons in this directory are sourced from Simple Icons.

Vite, MUI, Vercel, Font Awesome, i18next, and Axios. The Font Awesome logo here is only a historical technology icon for the Weather project; the portfolio itself no longer depends on the Font Awesome library.

Source:
https://github.com/simple-icons/simple-icons

Brand names and trademarks remain the property of their respective owners. Check the Simple Icons metadata and licensing information before reusing an individual brand asset.

## Fallback icons

Some technologies do not have a suitable Simple Icons brand icon. For example, `uuid` uses a Lucide icon fallback instead of a brand logo.
